## 範圍與修正

- 盤點草稿提示測試只接管 delay=3000 的提示 callback，查詢與 testkit 穩定等待仍走真實排程；保留提示存在、只通知一次、草稿連結、無紀錄及自動消失等原 assertions。避免真等三秒受負載拖累（單項約 0.2 秒）。結束時還原 timer，沒有改正式程式。

- 桌機／手機日期窗在 Radix onOpenAutoFocus 回呼聚焦所選日，避免日格 React autoFocus 早於 Scope 掛載而被外窗拉回。桌機初始焦點測試修正前失敗；只修桌機後，手機測試也重現，兩者補齊後通過。
- 非測試 src 中「保留 MUI／沿用 MUI／相容層 Dialog」等過時現況改為正式 ui 元件；正確的原 MUI 數值、事件簽名及歷史理由保留。compat-layer 仍是 live helper，現由 combobox 與多選清單使用；CLAUDE.md 僅同步這兩處架構事實，規則未改。
